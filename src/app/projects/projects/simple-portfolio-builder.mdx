## Overview

Once UI is an open-source design system built for modern web applications. It provides a comprehensive set of components, tokens, and patterns that help developers build consistent and accessible user interfaces.

## Key Features

- **Accessible**: Built with accessibility in mind, following WCAG guidelines
- **Responsive**: Mobile-first approach with flexible grid systems
- **Customizable**: Extensive theming capabilities with CSS custom properties
- **Performance**: Optimized for fast loading and smooth interactions
- **Documentation**: Comprehensive docs with live examples

## Technologies

- React
- TypeScript
- CSS Modules
- Storybook

## Impact

The design system has been adopted by multiple teams and has significantly reduced development time while improving UI consistency across projects.
